Chưa kết nối Firebase
Dán mã cấu hình Firebase bên dưới để đồng bộ dữ liệu thời gian thực giữa các thiết bị.
Cách lấy mã cấu hình miễn phí từ Google (chỉ mất 2 phút):
  1. Vào console.firebase.google.com, bấm Add project (Tạo dự án).
  2. Bấm Build > Firestore Database > Create Database (chọn Start in test mode).
  3. Vào Project Settings (Cài đặt bánh răng) > Your apps > Web (</>), copy đoạn firebaseConfig = { ... } dán vào ô trên.
